# أ. أحمد زين العابدين — Mr. Ahmed Zain Al-Abideen

ألعاب تفاعلية لمادة الرياضيات — الصف السابع.

- `index.html` : الصفحة الرئيسية (الدرسان)
- `game.html?l=1` : الدرس الأول — كتابة المعادلات وحلها
- `game.html?l=2` : الدرس الثانى — استنتاج واستخدام الصيغ (يشمل لعبتى شد الحبل وتسجيل الأهداف)
- `data/` : أسئلة كل درس (6 ألعاب × 15 سؤالًا، بدون وقت محدد)
- `assets/` : التصميم ومحرك الألعاب (يعمل بدون إنترنت عدا الخط)

للنشر على GitHub Pages: ارفع محتويات المجلد كما هى ثم فعّل Pages من الإعدادات على الفرع الرئيسى.
